# TAVF Research Questions

## RQ1

How does TAVF affect the quality of LLM-generated outputs compared with direct prompting across the three selected Agile software-development tasks?

## RQ2

How effective is task-specific validation in identifying quality issues in LLM-generated outputs for User Story Refinement, Bug Report Refinement, and Test Case Generation?

## RQ3

To what extent does the feedback and refinement stage in TAVF improve outputs that initially fail task-specific validation?

## RQ4

How does the effectiveness of TAVF differ across User Story Refinement, Bug Report Refinement, and Test Case Generation?

## RQ5

What is the additional execution cost of using TAVF compared with direct prompting in terms of response time, number of revisions, token usage, and estimated API cost?


RQ1 → quality scores / coverage / human evaluation
RQ2 → validation results and validation scores
RQ3 → raw output vs final output + number of revisions
RQ4 → comparison by task type
RQ5 → time + tokens + cost + revision count
