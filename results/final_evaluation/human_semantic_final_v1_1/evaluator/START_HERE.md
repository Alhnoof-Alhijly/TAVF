# Human Semantic Evaluation ? final package

This packet contains 100 paired inputs and 200 blinded outputs:
50 User Story pairs and 50 Bug Report pairs. No ratings have been assigned.

1. Read `rubric.md` (approved v1.1) and `rater_guidance.md`.
2. Open `scoring_sheet.csv` in a spreadsheet application using UTF-8 and comma
   separation. Source input and output text are included in each row; enable
   wrapped text. A readable paired packet is also provided as `samples.md`.
3. Keep IDs, source/output text, A/B labels, task type and applicable-criteria
   fields unchanged. Complete only the applicable rating/status/evidence fields.
4. Ratings are integers 1?5. Status is `rated`, `uncertain`, or `unassessable`.
   For unassessable criteria leave the rating blank and explain why in evidence.
   Leave all nonapplicable criteria blank. Add rater ID and assessment date.
5. Save a separate completed copy for each rater. Keep this blank master intact.

CSV is a data file, not executable content. Import source/output columns as text;
do not enable macros, external links, or automatic formula interpretation.
Method identities, automatic scores and internal validation statuses are excluded.
No private mapping is included. A/B labels are local to each sample.
