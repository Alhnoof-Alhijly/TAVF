# User Story Refinement Evaluation Rubric

Each generated user story is evaluated using eight criteria.

Scoring scale:

- 0 = Criterion not satisfied
- 1 = Partially satisfied
- 2 = Fully satisfied

Maximum total score: 16

| Criterion | Score 0 | Score 1 | Score 2 |
|---|---|---|---|
| Atomicity | Contains multiple distinct needs or goals | Some combined concerns remain | Expresses one clear user need |
| Minimality | Contains clear redundancy or unnecessary detail | Some unnecessary detail remains | Concise and direct |
| Conceptual Soundness | Role or requested feature is missing or unclear | One element is weak or partially clear | Role and requested feature are clear |
| Problem Orientation | Strongly prescribes a technical solution | Mixes user need with implementation details | Focuses on the user need rather than a technical solution |
| Unambiguity | Vague, general, or open to multiple interpretations | Some ambiguity remains | Clear and specific |
| Estimability | Too unclear or broad to estimate | Requires some additional clarification | Clear enough to estimate and implement |
| Means–Ends Relation | Benefit or rationale is missing or unclear | Benefit exists but is weakly connected | Clear relationship between the requested feature and its benefit |
| Intent Preservation | Changes the original meaning or introduces new requirements | Preserves most of the meaning with minor changes | Fully preserves the original intent without inventing new requirements |

## Overall Score Interpretation

- 0–5: Poor
- 6–10: Moderate
- 11–13: Good
- 14–16: High Quality
