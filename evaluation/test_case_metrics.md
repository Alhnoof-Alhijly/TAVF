# Test Case Generation Evaluation Metrics

The generated test cases will be evaluated using execution-based metrics derived from the TestEval benchmark.

## Core Metrics

### 1. Execution Success Rate

Measures whether the generated test code executes successfully without syntax or runtime errors.

**Calculation:**

Execution Success Rate =
Number of successfully executed test outputs /
Total number of generated test outputs

### 2. Test Correctness

Measures whether the generated tests behave consistently with the provided reference implementation and produce valid assertions.

A generated test set is considered correct when:
- the test code is executable;
- assertions are valid;
- the tests do not fail because of incorrect expected values.

### 3. Line Coverage

Measures the percentage of executable source-code lines covered by the generated tests.

**Calculation:**

Line Coverage =
Covered executable lines /
Total executable lines × 100

### 4. Branch Coverage

Measures the percentage of decision branches exercised by the generated tests.

**Calculation:**

Branch Coverage =
Covered branches /
Total branches × 100

### 5. Target Coverage

Measures how many TestEval target lines or target code regions are reached by the generated tests.

**Calculation:**

Target Coverage =
Covered target lines /
Total target lines × 100

The TestEval `target_lines` field will be used only during evaluation and will not be exposed to the LLM during test generation.

### 6. Number of Valid Generated Tests

Counts the number of generated test cases that are syntactically valid and executable.

This metric is recorded for each task to compare the amount of usable test output generated by Direct Prompting and TAVF.

## Optional Metric

### Path Coverage

Path coverage may be evaluated if additional analysis is required.

It is not included as a primary metric in the initial TAVF experiment because it requires additional path-specific evaluation procedures.

## Experimental Comparison

The same evaluation procedure will be applied to:

- Direct LLM Prompting
- TAVF

using the same 20 TestEval tasks and the same LLM.
